# Jani — instructions for Claude Code

Read `JANI_PLAN.md` in full first. This file summarizes the non-negotiable rules.

## What we are building
A PWA (React + Vite + TypeScript) that works offline and helps a coffee farmer decide, when facing a sign on a leaf: treat, wait or consult a person. A single engine + installable local packs (`packs/`).

## Acceptance criteria
1. The photo → diagnosis → risk → decision → voice route works in **airplane mode** after the first load.
2. The four modules (SEE, PREDICT, DECIDE, VOICE) are implemented and connected. None is left as a mockup.
3. No visible or spoken text is generated at runtime: everything comes from the active `pack.json`.
4. No agronomic or economic number lives in the code: everything comes from the pack, through `engine/resolve.ts`.
5. `resolve` uses the real value if it has a source; otherwise the one from `demo_values` and flags `usedDemoData`; if there is neither, the function returns `CONSULT`. It never invents a default value.
6. When `usedDemoData` is true, the screen shows the demo label.
7. Classes, normalization, temperature and thresholds are read from `app/public/models/arabica-v1/model_card.json`.
8. The app suggests; the person chooses. The choice is recorded.
9. The `.wasm` files of `onnxruntime-web` go in `public/ort/`, not from a CDN.
10. Photos do not leave the phone. The escalation SMS carries text only.
11. Tests P1–P4 and D1–D4 from `JANI_PLAN.md` pass with the exact numbers in the tables.

## Code rules
- Strict TypeScript. `engine/predict.ts` and `engine/decide.ts` are pure functions with Vitest tests.
- Interface for low digital literacy: big buttons, icons, one action per screen, automatic audio.
- Small commits, one per step of the plan.
- Do not touch `training/jani_train.ipynb` unless asked: a person runs it in Colab.

## Work order
Follow section 13 of `JANI_PLAN.md`, one prompt at a time. Do not wait for the real model: while `recommended_file` is `null`, `see` works in simulated mode.

## Status of the inputs
- `packs/*/pack.json`: complete structure, 38 phrases and `demo_values` so that DECIDE works today. The real values (`calendar`, `economics`) are `null` with `source: "TODO"`; the team fills them in without touching code.
- `packs/*/audio/`: generated by the team with `training/make_audio.py` or by recording. If an audio file is missing, `voice.ts` must not fail (section 7.2).
- `app/public/models/arabica-v1/`: currently holds an example card; the team replaces it with the output of `training/jani_train.ipynb`.
